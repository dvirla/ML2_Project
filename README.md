# Image Annotator and Colorizer with Deep Learning

## Overview

This project showcases a deep learning-based image captioning model inspired by the *Show, Attend and Tell* paper (2016), It integrates natural language processing and computer vision techniques to generate descriptive captions for images using attention mechanisms.

Developed as part of an academic course in 2021, the project applies advanced methods for its time, offering insights into image captioning, colorization and evaluation metrics.

## **Key Features**

-   **Image Captioning with Attention**: Generates captions by focusing on image regions using an attention mechanism and RNN-based decoding.

-   **Image Colorization Model**: Adds color to grayscale images with an autoencoder-based architecture to test its impact on captioning.

-   **Grayscale and Colorization Experiments**: Compares model performance with original, grayscale, and colorized images.

-   **GAN-Aided Captioning**: Enhances sentence fluency and coherence using a generative adversarial network (GAN).

-   **Evaluation with BLEU Scores**: Quantifies model accuracy across formats with detailed BLEU score comparisons.
